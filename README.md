# CryptoBot — автономная торговля криптофьючерсами

Полностью автономный торговый бот для бирж **YoBit** и **MEXC**.
Работает на ПК под Windows (Python 3.11+), управляется удалённо через диалоги **ВКонтакте**,
показывает живой дашборд с ликвидными парами в окне.

Не требует VPS или облака — всё на локальной машине.

---

## Возможности

### 1. Автономная торговля
- Самостоятельно определяет баланс счёта (free + locked по валюте пары)
- Рассчитывает размер лота от капитала: `капитал × RISK_PERCENT% × плечо`
- Автоматически повышает риск (до `MAX_RISK_PERCENT`), если минимальная сделка пары больше расчётной — сделка всегда проходит
- Открывает позицию → мониторит → закрывает по TP/SL → ждёт cooldown → открывает снова
- Чередует BUY/SELL: лонг → шорт → лонг → ...
- Состояние сохраняется в `position.json` — переживает перезапуск

### 2. Риск-менеджмент
- Лимит суммы ордера (`MAX_NOTIONAL_PER_ORDER_USD`)
- Лимит плеча (1–20x)
- Авто SL/TP в % от цены входа (`SL_PERCENT`, `TP_PERCENT`) или фиксированные
- Cooldown между сделками (`AUTO_COOLDOWN_SEC`)
- Режим `DRY_RUN` — тест без реальных ордеров
- Учёт комиссий биржи в отчёте (`TRADE_FEE`, по умолчанию 0.2%)

### 3. Авто-выбор пары
- Команда `пары` — список ликвидных USDT-пар, отсортированных по стоимости минимальной сделки
- Фильтр ликвидности: отсекает мёртвые пары по объёму торгов (`MIN_PAIR_VOLUME_USD`)
- Команда `авто пара` — бот сам находит самую дешёвую ликвидную пару под текущий баланс

### 4. Управление через ВКонтакте
- Подключение через Long Poll API сообщества (группы)
- Команды принимаются только от админов (`VK_ADMIN_IDS`)
- Ответы приходят в тот же диалог/беседу
- Распознавание по первому слову — «проверка как дела» тоже сработает

| Команда | Действие |
|---------|----------|
| `Стоп` / `Старт` | Пауза / возобновление торговли |
| `Проверка` | Баланс, цена, позиция, PnL |
| `Отчёт` | Чистая прибыль, ROI, комиссии, винрейт |
| `Сделки` | Последние закрытые сделки |
| `Исполнено` | Сколько от текущего ордера исполнено |
| `Пары` | Список ликвидных пар по номерам |
| `выбор N` | Выбрать пару из списка |
| `авто пара` | Бот сам подберёт пару под баланс |
| `пара BTC_USDT` | Сменить пару вручную (сброс позиции) |
| `команды` | Показать справку |

### 5. Дашборд в окне (GUI)
- Таблица ликвидных пар обеих бирж (YoBit + MEXC) — обновление каждые 15 сек
- Статус-бар (режим, пауза, позиция)
- Живой лог всех действий

### 6. Отчёт о прибыли
- Каждая закрытая сделка пишется в `report.json`: PnL, комиссия, чистая прибыль
- Стартовый капитал фиксируется при первой сделке
- ROI = (текущий баланс − стартовый) / стартовый × 100%
- Статистика: сделки, winrate, последняя сделка

### 7. Гибкое расписание
- `SCHEDULE=24/7` — круглосуточно
- Или окна: `TRADE_WINDOWS="10:00-18:00,20:00-22:00"`, поддержка окон через полночь

## Биржи

| Биржа | API | Особенности |
|-------|-----|-------------|
| YoBit | v3, HMAC-SHA512, TAPI | ~9000 пар, фьючерсы, без KYC |
| MEXC | v3, HMAC-SHA256 | Спот API, топ по объёму |

Переключение одной строкой: `EXCHANGE=yobit` / `EXCHANGE=mexc`.
Символы в формате `BTC_USDT` (бот сам конвертирует в `BTCUSDT` для MEXC).

## Архитектура

```
bot.py          — ядро: клиенты бирж, авто-торговля, команды ВК, отчёты
gui.py          — окно tkinter: дашборд пар + лог (в главном потоке)
vk_control.py   — Long Poll ВК: приём сообщений, обработка обрывов
setup.py        — оболочка настроек: поля для ключей, запуск/остановка
.env            — конфигурация и ключи
position.json   — текущая позиция
report.json     — история сделок и прибыль
```

- Запуск через `pythonw.exe` — без окна консоли
- Гуи в главном потоке, торговля — в фоновом (daemon)
- Watchdog (`run_bot_watchdog.bat`) — перезапуск при падении
- Автозагрузка — bat в папке Startup Windows

## Установка

### Из исходников (нужен Python 3.11+)
```bash
pip install python-dotenv requests
python setup.py   # оболочка настроек
python bot.py     # бот
```

### Готовый пакет (exe, Python не нужен)
Скачайте `CryptoBot_install.zip` из [GitHub Release](https://github.com/magistr666/BOTtorgi/releases/tag/v1.0.0):
- `setup.exe` + `bot.exe` — автономные (PyInstaller)
- `install.bat` — установщик: сам ставит Python 3.13 при необходимости, копирует в `C:\CryptoBot`, создаёт ярлык

### Автозапуск с Windows
```
C:\Users\User\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\YoBitBot_autostart.bat
```

## Демо-режим

- `DEMO_DAYS=21` в `.env` — срок бесплатного использования
- При первом запуске создаётся маркер `.demo_start`
- После истечения срока бот блокируется, уведомляет в ВК и самоудаляет файлы
- `DEMO_DAYS=0` — режим отключён (полная версия)

## Безопасность

- `.env` с ключами — в `.gitignore`, не публикуется в репозиторий
- Ключи API создаются **без права Withdraw** (вывод средств отключён)
- Команды ВК принимаются только от ID из `VK_ADMIN_IDS`
- Уведомления о каждой сделке/ошибке приходят в ВК

## Известные технические решения

- **Nonce для YoBit** — строго возрастающий счётчик (не timestamp, иначе ошибка «max 2147483646»)
- **TAPI хост** — `https://yobit.net/tapi/` (не `yobit.io` — там невалидный сертификат)
- **Пакетные тикеры YoBit** — разделитель пар в запросе: дефис `-` (не запятая)
- **GUI не умирает при закрытии окна** — бот продолжает работу в фоне
- **Long Poll переживает обрывы** — обработка кодов failed=1/2/3 с переподключением
