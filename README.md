# CryptoBot — автономная торговля на YoBit и MEXC

Полностью автономный торговый бот для криптобирж **YoBit** и **MEXC**.
Работает на Windows (Python 3.11+), управляется через диалог **ВКонтакте**,
показывает живой дашборд в окне.

## Возможности

- **Автономная торговля** — сам открывает позицию, ждёт TP/SL, закрывает, повторяет
- **Чередование BUY/SELL** — лонг, шорт, лонг...
- **Авто-объём под баланс** — рассчитывает лот от капитала, сам повышает риск для минимальной сделки
- **Авто-выбор пары** — находит самую дешёвую ликвидную пару под баланс
- **Риск-менеджмент** — лимит суммы, плечо, cooldown, SL/TP, dry-run
- **Дашборд** — топ ликвидных пар обеих бирж в окне (tkinter)
- **Управление через ВК** — команды из беседы/чата сообщества (Long Poll)
- **Отчёт о чистой прибыли** — ROI, комиссии, винрейт (по команде «Отчёт»)
- **Демо-режим** — ограничение по дням с блокировкой (DEMO_DAYS)

## Команды в ВК

| Команда | Действие |
|---------|----------|
| `Стоп` / `Старт` | Пауза / возобновление торговли |
| `Проверка` | Баланс, цена, текущая позиция |
| `Отчёт` | Чистая прибыль, ROI, статистика |
| `Сделки` | Последние закрытые сделки |
| `Исполнено` | Сколько от текущего ордера исполнено |
| `Пары` | Список ликвидных пар по номерам |
| `выбор N` | Выбрать пару по номеру |
| `авто пара` | Бот сам подберёт пару под баланс |
| `пара BTC_USDT` | Сменить пару вручную |
| `команды` | Показать справку |

## Быстрый старт

```bash
pip install python-dotenv requests
# заполнить .env (см. .env.example)
python setup.py   # оболочка настроек
python bot.py     # сам бот
```

Или установите готовый пакет: `setup.exe` (оболочка) + `bot.exe` (бот), Python не нужен.

## Конфигурация (.env)

| Параметр | Описание |
|----------|----------|
| `EXCHANGE` | `yobit` или `mexc` |
| `SYMBOL` | торговая пара, напр. `FLOKI_USDT` |
| `LEVERAGE` | плечо |
| `RISK_PERCENT` | % капитала на позицию |
| `CAPITAL_ASSET` | валюта капитала (USDT) |
| `MAX_NOTIONAL_PER_ORDER_USD` | лимит суммы ордера |
| `DRY_RUN` | `true` — тест без реальных ордеров |
| `MODE` | `auto` / `monitor` / `trade` |
| `DEMO_DAYS` | демо-срок в днях, `0` — без ограничений |
| `VK_TOKEN` | токен сообщества ВК |
| `VK_GROUP_ID` | ID группы |
| `VK_PEER_ID` | ID беседы |
| `VK_ADMIN_IDS` | ID админов через запятую |

## Структура

```
bot.py          — основная логика (клиенты бирж, авто-торговля, ВК-команды)
gui.py          — окно tkinter: дашборд + лог
vk_control.py   — Long Poll ВК (приём команд)
setup.py        — оболочка настроек и запуска
```

## Безопасность

- `.env` содержит секреты — он в `.gitignore`, не публикуйте его
- Создавайте API-ключи без права Withdraw
- ВК-команды принимаются только от ID из `VK_ADMIN_IDS`
